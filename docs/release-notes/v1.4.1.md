# Quantum Leap v1.4.1

## 亮点

Quantum Leap 1.4.1 加入签名应用内更新，并重新组织测速会话、SSH 与 iperf3 执行核心，使关键状态和清理流程拥有更清晰的边界与更完整的回归测试。

## 新功能与改进

- 启动后自动检查更新，也可在设置中手动检查。
- macOS、Windows 与 Linux AppImage 支持显示版本说明、下载进度、安装并重新启动。
- Linux DEB 安装会打开 GitHub Release 页面，避免绕过包管理器直接替换文件。
- 将前端端点配置、表单验证、结果展示与测速会话状态拆分为独立模块，并增加针对这些流程的测试。
- 将 Rust 测速核心拆分为会话计划、运行时、退出清理、iperf3 解析/执行与 SSH 操作模块，保留现有本机测速、双端互测和进程生命周期行为。
- 完善更新失败、测速进行中暂缓安装、无更新说明以及外部下载等界面状态。

## 下载与安装

- **macOS ARM64：**打开 DMG，将 Quantum Leap 拖入 Applications。
- **Windows x64：**运行 NSIS 安装程序。
- **Linux x64/ARM64：**运行 AppImage，或安装对应架构的 DEB。

这是首个包含更新器的引导版本，因此从 1.4.0 或更早版本升级时仍需手动安装 1.4.1。安装完成后，后续版本可通过应用内更新获取；DEB 用户仍会转到 Release 页面。

## 兼容性与签名

- macOS 13 Ventura 或更高版本，Apple Silicon (`arm64`)
- Windows 10/11 (`x64`)
- 使用 glibc 的 Ubuntu/Debian x64 或 ARM64 桌面环境
- macOS 应用使用 ad-hoc 系统签名且未经过 Apple 公证；Windows 与 Linux 安装包未进行商业代码签名
- 应用内更新包另有 Tauri updater 签名，用于验证下载完整性和发布者密钥，不等同于操作系统商业代码签名

## 完整性

所有公开附件的 SHA-256 摘要收录在 `SHA256SUMS-v1.4.1.txt` 中。

## Highlights

Quantum Leap 1.4.1 introduces signed in-app updates and reorganizes the speed-test session, SSH, and iperf3 execution core into focused modules with broader regression coverage.

## Changes

- Checks for updates automatically at launch and manually from Settings.
- Shows release notes and download progress, then installs and restarts on macOS, Windows, and Linux AppImage installations.
- Opens the GitHub Release page for Linux DEB installations so package-managed files are not replaced directly.
- Separates endpoint configuration, form validation, results, and session state into focused frontend modules with dedicated tests.
- Separates session planning, runtime, exit cleanup, iperf3 parsing/execution, and SSH operations in the Rust core while preserving existing test topologies and process lifecycle behavior.
- Covers update failures, active-test installation blocking, missing release notes, and external-download states.

## Installation note

This is the updater bootstrap release. Existing 1.4.0 and earlier installations must install 1.4.1 manually once. Later releases can use the in-app updater, while DEB installations continue to open the Release page.

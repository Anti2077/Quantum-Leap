# Quantum Leap v1.4.3

## 修复

- 修复 Linux AppImage 启动器权限，普通用户可以正常启动应用。
- Linux AppImage 发布文件名按架构标识，移除多余的 `Linux` 字样。
- Linux x64 与 ARM64 发布流程增加 AppImage 权限和窗口启动检查。

## Fixes

- Fixes Linux AppImage launcher permissions so ordinary users can start the application.
- Uses architecture-specific AppImage release names without the redundant `Linux` segment.
- Adds AppImage permission and window startup checks to the Linux x64 and ARM64 release jobs.

## 下载与安装

- **macOS Universal：**下载 `Quantum-Leap_1.4.3_macOS_universal.dmg`，打开后将 Quantum Leap 拖入 Applications。
- **Windows x64：**下载 `Quantum-Leap_1.4.3_Windows_x64_portable.zip`，完整解压后运行 `Quantum Leap.exe`。
- **Linux x64：**运行 `Quantum-Leap_1.4.3_x86_64.AppImage`，或安装对应的 DEB 软件包。
- **Linux ARM64：**运行 `Quantum-Leap_1.4.3_aarch64.AppImage`，或安装对应的 DEB 软件包。

## Installation

- **macOS Universal:** Download `Quantum-Leap_1.4.3_macOS_universal.dmg`, open it, and drag Quantum Leap to Applications.
- **Windows x64:** Download `Quantum-Leap_1.4.3_Windows_x64_portable.zip`, extract it completely, and run `Quantum Leap.exe`.
- **Linux x64:** Run `Quantum-Leap_1.4.3_x86_64.AppImage` or install the matching DEB package.
- **Linux ARM64:** Run `Quantum-Leap_1.4.3_aarch64.AppImage` or install the matching DEB package.

macOS uses an ad-hoc signature and is not notarized by Apple. Windows and Linux packages do not use commercial code signing. SHA-256 hashes for public assets are listed in `SHA256SUMS-v1.4.3.txt`.

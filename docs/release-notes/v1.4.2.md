# Quantum Leap v1.4.2

## 亮点

Quantum Leap 1.4.2 为 macOS 增加 Intel 支持，并改进 UDP 上传结果的准确性。macOS 现在提供同时包含 Apple Silicon 与 Intel 架构的 Universal 2 软件包。

## 新功能与改进

- macOS 应用和更新包改为 Universal 2 构建，同一个 DMG 同时支持 `arm64` 与 `x86_64`。
- UDP 上传完成后使用接收端汇总速率，避免将发送端目标速率误作实际接收吞吐量。
- UDP 结果新增接收端平均速率、丢包率、抖动和已接收数据量，并区分发送端实时采样与接收端最终统计。
- Windows 发布包改为免安装的 x64 绿色版 ZIP，包含本机测速所需的 iperf3 与运行库；应用内更新会转到 Release 页面下载新版本。
- README 新增各版本、各平台发布包的下载量统计。

## 下载与安装

- **macOS Universal：**下载 `Quantum-Leap_1.4.2_macOS_universal.dmg`，打开后将 Quantum Leap 拖入 Applications。
- **Windows x64：**下载 `Quantum-Leap_1.4.2_Windows_x64_portable.zip`，完整解压后运行 `Quantum Leap.exe`，不要拆分目录内文件。
- **Linux x64/ARM64：**运行对应架构的 AppImage，或安装 DEB 软件包。

macOS 软件包使用 ad-hoc 签名，未经过 Apple 公证。首次启动时请在 Applications 中右键 Quantum Leap 并选择“打开”；如果仍被阻止，请前往“系统设置 > 隐私与安全性”选择“仍要打开”。

## 兼容性与签名

- Apple Silicon 或 Intel Mac 上的 macOS 13 Ventura 或更高版本
- Windows 10/11 (`x64`)
- 使用 glibc 的 Ubuntu/Debian x64 或 ARM64 桌面环境
- macOS 应用使用 ad-hoc 系统签名且未经过 Apple 公证；Windows 与 Linux 发布包未进行商业代码签名
- macOS 与 Linux AppImage 更新包另有 Tauri updater 签名，用于验证下载完整性和发布者密钥

## 完整性

所有公开附件的 SHA-256 摘要收录在 `SHA256SUMS-v1.4.2.txt` 中。

## Highlights

Quantum Leap 1.4.2 adds Intel Mac support and improves the accuracy of UDP upload results. macOS now ships as a Universal 2 package containing both Apple Silicon and Intel architectures.

## Changes

- Ships one Universal 2 macOS app and updater package for both `arm64` and `x86_64` Macs.
- Uses the receiver summary for completed UDP uploads instead of presenting the sender's target rate as received throughput.
- Shows receiver average throughput, packet loss, jitter, and received bytes for UDP results while distinguishing live sender samples from final receiver statistics.
- Replaces the Windows installer with a self-contained x64 portable ZIP that includes iperf3 and its runtime files; in-app updates open the Release page for manual replacement.
- Adds per-release, per-platform package download statistics to the README.

## Download and Install

1. Download the package for your platform. Intel and Apple Silicon Mac users share `Quantum-Leap_1.4.2_macOS_universal.dmg`.
2. On macOS, open the DMG and drag Quantum Leap into Applications. On Windows, extract the complete portable ZIP before running `Quantum Leap.exe`. On Linux, run the AppImage or install the DEB.
3. This macOS release uses an ad-hoc signature and is not notarized by Apple. On first launch, right-click the app in Applications and choose Open. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway.

## Compatibility

- macOS 13 Ventura or later on Apple Silicon or Intel
- Windows 10/11 x64
- x64 or ARM64 Ubuntu/Debian desktop using glibc
